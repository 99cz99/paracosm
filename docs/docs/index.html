文档

Paracosm 是一款纯客户端的 AI 角色扮演 App：用户自带 API key，本地 SQLite 存储，和 AI 角色聊天、玩视觉小说剧情。无服务器、无账号、无云同步。

目录

  • 快速开始 —— 环境准备、构建、部署到手机、测试连接。
  • 功能特性 —— 聊天、群聊、剧情、世界书、记忆系统、Skill 成长等。
  • 技术架构 —— 技术栈、项目结构、关键设计约定。

一句话定位

你提供 API key，其余全部在本地：角色卡（酒馆卡 / Skill）导入、世界书注入、长期记忆、群聊、分支剧情，数据不经过任何服务器。

支持 OpenAI 兼容接口（DeepSeek / Kimi / GLM / SiliconFlow / OpenAI）与 Anthropic Messages API，可在「我 → API Provider」里配置并点选切换。
