技术架构

技术栈

层面选型
框架Flutter（Android 优先）
状态管理Riverpod 3
数据库SQLite + Drift（drift_flutter）
Key 存储flutter_secure_storage（仅 API key）
流式dio + SSE（ResponseType.stream + 行解析）
路由go_router（五 Tab StatefulShellRoute）
后台保活flutter_background_service（前台服务）
拼音排序lpinyin

项目结构（feature-first）

lib/
  core/
    config/       # AppConfig（schemaVersion 等）
    db/           # tables.dart + database.dart（Drift 表 + 查询）
    network/llm/  # LlmProvider 抽象 + OpenAI 兼容/Anthropic 实现 + mock + 翻译器
    network/sse/  # SSE 行解析
    storage/      # flutter_secure_storage 封装
    import/       # 酒馆卡/Skill 解析 → ImportedCharacter
    backup/       # JSON 全量备份/恢复
    background/   # 后台保活
    providers/    # dbProvider、secureKeyStoreProvider、resolveProvider
    router/ theme/ utils/
  features/
    chat/         # 会话列表 + 单聊流式 + 开场白切换
    contacts/     # 联系人 + 导入 + 角色详情/编辑
    group_chat/   # 群聊（多角色 + 三模式 + 角色对关系）
    story/        # 剧情（AI 生成 + 分支树 + 回退 + 存档）
    worlds/       # 异世界 CRUD
    profile/      # 「我」+ API Provider 配置
    home/         # 五 Tab 底部导航壳
    search/       # 角色/消息搜索

关键设计

  • LLM Provider 抽象：LlmProvider.streamChat() 返回 Stream<ChatChunk>；活跃配置每次发送时现场解析（resolveActiveProvider）。
  • 全局流式控制器：聊天 / 群聊控制器是全局 NotifierProvider，离开页面仍继续跑；落库前校验会话 / 群是否存在。
  • 五 Tab 路由：StatefulShellRoute.indexedStack；Tab 切换按 index 决定是否重置导航栈。
  • Schema 迁移：改表同步 AppConfig.schemaVersion + migration.onUpgrade 分支，再 build_runner 重生成。
  • 世界书注入统一：WorldbookMatcher（关键词匹配）+ WorldContextBuilder（合并实体绑定与世界绑定世界书）。
弹窗一律 useRootNavigator: false，否则会与 go_router 根 Navigator 冲突导致黑屏；提示统一走弹窗，不用 snackbar。

构建工具

改表结构后需重新生成 Drift 代码：

dart run build_runner build

启动图标由 tool/gen_icon.py 生成（像素风对话框，五档 PNG + 自适应图标 + 矢量前景）。
