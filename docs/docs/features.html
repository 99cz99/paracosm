功能特性

角色导入与三层解耦

支持酒馆卡（PNG / JSON，V1/V2/V3）与 Skill（ZIP / Markdown）导入，统一为 ImportedCharacter。

  • 角色 core：Characters.corePersonaJson（SillyTavern persona）
  • 世界适配 adaptation：CharacterAdaptations（默认 worldId=''）
  • 世界书：角色内置世界书（随角色存）+ 共享世界书库（多对多绑定）

同一角色在不同世界各自独立：世界适配、关系、Skill 成长、记忆均按「角色 × 世界」隔离。

单聊

  • SSE 流式回复，后台继续生成（前台服务保活）；中断时保留部分回复。
  • 开场白自动发出，聊天内 ←/🎲/→ 切换（用户回复后隐藏）；英文开场白可逐条翻译缓存。
  • 一个「角色 × 世界」一个会话；「全新开始」清空该世界记忆并重建。
  • 每会话可指定 API provider 与采样参数（温度 / maxTokens / penalty）+ 采样预设。
  • 长按消息撤回、复制。

群聊 · 三模式

  • 多角色同屏对话，三种模式，角色对关系（CharacterRelations）驱动互动。
  • 成员独立记忆可开关（Groups.memoryEnabled），支持多世界绑定。

剧情 · 分支树

  • AI 生成剧情节点，选择推进分支；复用已生成分支，未命中才生成。
  • 「重来」覆盖当前节点并删子树；分支树可跳转 / 编辑 / 删除。
  • 存档与回退；choices 空数组即结局。

记忆系统

  • 每轮回复后异步抽取「结构化状态 + 滚动摘要」，存 CharacterMemories（按角色 × 世界复合主键）。
  • 世界书按关键词注入 system prompt（纯字符串匹配，无 LLM）。
  • 关系与 Skill 成长按「角色 × 世界」隔离，删会话即删该角色 × 世界的记忆。

Skill 成长

带 core['affinity'] 的角色走 skill 自带三轴数值规则（信任 / 堕落度 / H 场景）。每轮单聊回复后由记忆模型产出更新 JSON，clamp 后写回 CharacterAffinities。

其他

  • 搜索：角色 / 消息搜索。
  • 备份/恢复：JSON 全量导出导入（含 providerConfigs；API key 不存）。
  • 联系人：首字母拼音排序（lpinyin）+ 置顶 + A-Z 索引条；批量导入；头像裁剪。
  • 世界书库：JSON / Markdown / zip 导入 + 手动编辑，绑定到角色 / 世界 / 群聊 / 剧情。
  • 角色编辑：完整人设（system_prompt / mes_example / 备注 / 昵称 / 后置指令），改完下一条消息即生效。
