快速开始

从零构建并跑起 Paracosm（Android 优先，Android-only 工程）。

1. 环境要求

组件说明
Flutter SDKstable（如 3.47.x，Dart 3.x）
Android SDKplatform 36 / build-tools 36.0.0
JDK17
设备实体 Android 手机，或已启用硬件加速的模拟器
需要设置环境变量：ANDROID_HOME、JAVA_HOME，并让 flutter 在 PATH 中。

2. 拉依赖

flutter pub get

3. 静态检查 / 测试

flutter analyze          # 目标 0 issue
flutter test             # 单元测试（纯 Dart + 内存 DAO）

4. 构建 & 部署

推荐分步部署（比 flutter run 更稳）：

flutter build apk --debug
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb shell am start -n com.paracosm.app/.MainActivity

打 release 包：

flutter build apk --release        # 通用 APK
flutter build apk --release --split-per-abi   # 按 ABI 拆分，更小

5. 配置 API Provider

打开 App → 「我」→「API Provider」→ 填入你的 API key（支持 OpenAI 兼容接口与 Anthropic）。可用「测试连接」验证，点选切换当前 provider。

API key 仅保存在本机（flutter_secure_storage），不会随备份导出、也不会同步到任何服务器。
