使用说明

三步上手：准备 API key → 导入角色 → 开始聊天。

  1. 准备 API key 前往你常用的模型服务商（DeepSeek / Kimi / GLM / SiliconFlow / OpenAI / Anthropic 等）获取 API key。
  2. 安装并配置 下载 APK 安装（Android 需允许「安装未知来源应用」），打开 App 进入「我 → API Provider」，填入 key 并「测试连接」。
  3. 导入角色 在「联系人」导入酒馆卡（PNG / JSON）或 Skill（ZIP / MD），也可以手动创建角色。
  4. 开始玩耍 单聊、群聊、剧情、异世界随意切换；记忆与世界书会自动注入，无需额外设置。

常见问题

支持哪些模型？

兼容 OpenAI 接口（DeepSeek / Kimi / GLM / SiliconFlow / OpenAI）与 Anthropic Messages API，可在「我 → API Provider」点选切换。

数据存在哪？

全部存于本机 SQLite，无账号、无云同步。卸载前请记得备份。

API key 安全吗？

仅加密存于本机（系统安全存储），不随备份导出，只在请求时发送给你配置的模型服务商。

怎么备份 / 迁移？

「我 → 备份」导出 JSON 文件，换机后「恢复」导入即可。

收费吗？

App 免费；聊天消耗你自备 API key 的额度，按各服务商计费。

隐私说明

无服务器、无账号、无云同步

App 不架设任何后端，不收集账号，不把数据同步到云端。

数据仅存本地

角色、剧情与记忆只保存在本机 SQLite 数据库中。

API key 仅本机加密存储

仅用于请求你配置的服务商，不传给任何第三方。

备份文件自行保管

导出的备份包含你的对话数据，请勿公开分享。
