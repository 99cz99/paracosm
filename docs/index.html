Paracosm

纯客户端 AI 角色扮演 App

和 AI 角色聊天、玩视觉小说剧情。用户自带 API key，本地 SQLite 存储 —— 无服务器、无账号、无云同步，你的角色、剧情与记忆只属于你。

查看文档 GitHub 仓库

核心特性

从酒馆卡导入到长期记忆，一套完整的本地角色扮演工作流。

💬

单聊流式

SSE 流式回复，后台继续生成；开场白自动发出，聊天内 ←/🎲/→ 切换。

👥

群聊 · 三模式

多角色同屏，三种对话模式 + 角色对关系，成员独立记忆可开关。

📖

剧情 · 分支树

AI 生成剧情，分支树可跳转/回退/存档，重新生成覆盖子树。

🌍

世界书

关键词注入的世界规则；角色内置世界书 + 共享世界书库多对多绑定。

🧠

记忆系统

结构化状态 + 滚动摘要，按「角色 × 世界」隔离；Skill 三轴成长。

🔒

隐私本地

无账号、无云同步；API key 加密存本机，数据可全量备份/恢复。

技术栈

Android 优先，纯 Flutter 工程。

Flutter Riverpod 3 Drift / SQLite dio + SSE go_router OpenAI 兼容 / Anthropic

快速开始

自备 API key（DeepSeek / Kimi / GLM / SiliconFlow / OpenAI / Anthropic 等均可）。

flutter pub get
flutter build apk --debug
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb shell am start -n com.paracosm.app/.MainActivity

完整的环境配置与部署说明见 构建文档。
